## 当前实现

m33核使用串口接收处理GPS和imu模块数据，检测imu数据异常，判断为摔倒，急刹，路面颠簸时，将imu，gps数据和警告通过OPENAMP传给A核，a核使用脚本读取和输出imu和gps数据；
m33核识别周围车辆蓝牙广播，当对方在运动时（过滤静止无威胁车辆），生成警报通过OPENAMP传给A核，a核使用脚本读取和输出警报；

A核 `radar_fusion` 程序已集成 IMU 摔倒检测作为 DVR 行车记录的触发源之一：
- 雷达 TTC 危险 + NPU 确认目标 → 触发保存
- M33 IMU 摔倒告警 → 触发保存
  - 若已有目标缓冲，保存前后各 15 秒（约 30 秒）
  - 若摔倒时无目标缓冲，从摔倒瞬间开始保存 15 秒

完整使用说明参见：[`mier/camera_detect/IMU_FALL_TEST.md`](../camera_detect/IMU_FALL_TEST.md)

## 启动命令
### m核启动
m核固件已经存放在~/project/lib/firmware/，使用~/project下的脚本可以启动m核
命令：
```bash
cd ~/project && ./fw_cortex_m33.sh start
```

### a核启动（单独监听 M33 告警）
a核接收脚本已经存放在~，并给予执行权限
命令：
```bash
cd ~ 
./a35_read_v2x_alerts.sh
```

### a核启动（完整 DVR 融合系统，推荐）
```bash
cd /xxl/camera_detect
./start_dvr.sh
```

模拟摔倒测试（无需晃动 IMU）：
```bash
cd /xxl/camera_detect
./start_dvr.sh -t 10
```

## 引脚连接：用 UART9 扩展 4 路串口设备

### 硬件连接

| 功能 | LD25X J13 | TTL 拓展模块 | 外部设备 |
|---|---|---|---|
| 公共发送 | Pin 8 / PG8_UART9_TX | RXD | 由 TX0～TX3 分别接设备 TX |
| 公共接收 | Pin 10 / PI5_UART9_RX | TXD | 由 RX0～RX3 分别接设备 RX |
| 供电 | Pin 1 或 17 / VDD_3V3 | VCC | - |
| 地 | 任意 GND | GND | 设备 GND 共地 |
| 通道选择 | PIN13/PI6 | A | - |
| 通道选择 | PIN15/PI7 | B | - |
| 使能 | 悬空 | EN | - |

| 拓展模块通道 | 外部设备连接方式 |
|---|---|
| TX0 → 蓝牙模块 TX，RX0 ← 蓝牙模块 RX，GND ↔ GPS GND |
| TX1 → GPS TX，RX1 ← GPS RX，GND ↔ GPS GND |
| TX2 → IMU TX，RX2 ← IMU RX，GND ↔ IMU GND |


### 通道切换逻辑

| 目标设备 | B | A | 需要连接的拓展通道 |
|---|---:|---:|---|
| 设备 0 | 0 | 0 | TX0/RX0 |
| 设备 1 | 0 | 1 | TX1/RX1 |
| 设备 2 | 1 | 0 | TX2/RX2 |
| 设备 3 | 1 | 1 | TX3/RX3 |
